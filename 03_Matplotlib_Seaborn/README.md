# Matplotlib Seaborn 

**Matplotlib и Seaborn — это основные библиотеки визуализации данных в Python**, которые превращают таблицы и массивы чисел в наглядные графики и диаграммы.

Они переводят сухие цифры в визуальные образы, чтобы человек мог быстро понять структуру информации. В сфере искусственного интеллекта эти инструменты служат для контроля качества данных и отслеживания работы моделей.

### Разница между Matplotlib и Seaborn

- **Matplotlib**: Базовая библиотека с полным контролем над каждым элементом графического холста. Вы настраиваете на ней линии, оси, цвета и сетки вручную. Код получается длинным, но позволяет сделать график любой сложности.
- **Seaborn**: Надстройка над Matplotlib для красивой статистической графики. Она строит сложные диаграммы одной строчкой кода и сразу применяет современный дизайн.

### Для чего они нужны в AI-инженерии

1. **Разведочный анализ данных (EDA)**: Поиск скрытых закономерностей, зависимостей и ошибок в таблицах до отправки их в модель.
2. **Контроль обучения нейросетей**: Построение кривых обучения, где видно, как со временем уменьшается ошибка (Loss) и растет точность (Accuracy) модели.
3. **Поиск выбросов**: Обнаружение аномальных значений, которые могут испортить результаты обучения алгоритма.
4. **Отображение матриц**: Визуализация матриц корреляции признаков или матриц ошибок (Confusion Matrix) для классификации.

### Где они используются

- **Data Science**: Для защиты и презентации результатов анализа данных заказчикам или команде.
- **Машинное обучение**: Внутри Jupyter Notebooks при создании прототипов и отладке алгоритмов.
- **Финансы и трейдинг**: Для отображения динамики цен, объемов торгов и технических индикаторов.

Простой код на Matplotlib и Seaborn, который строит базовый график обучения модели (динамику падения ошибки от эпохи к эпохе):

```python
import matplotlib.pyplot as plt
import seaborn as sns

# Включаем красивый стандартный стиль Seaborn
sns.set_theme()

# Данные: номера эпох обучения и значения ошибки (Loss)
epochs = [1, 2, 3, 4, 5]
loss_values = [0.95, 0.62, 0.38, 0.19, 0.08]

# Создаем размер холста
plt.figure(figsize=(8, 4))

# Рисуем линию графика с точками
plt.plot(epochs, loss_values, marker='o', color='red', label='Ошибка (Loss)')

# Добавляем подписи осей и заголовок
plt.title('График падения ошибки модели')
plt.xlabel('Эпоха обучения')
plt.ylabel('Уровень ошибки')

# Показываем легенду и сам график
plt.legend()
plt.show()
```
