# Scikit learn

**Scikit-learn** (часто пишется как sklearn) — это **главная и самая популярная библиотека на Python для классического машинного обучения**.

Если современные нейросети (PyTorch, TensorFlow) создаются для распознавания лиц и генерации текста, то Scikit-learn отвечает за работу со стандартными структурированными данными (таблицами) и **подготовку этих данных перед подачей в абсолютно любую модель**.

Она построена поверх NumPy, SciPy и Matplotlib, что делает её быстрой и удобной в работе.

### ⚙️ Зачем используется Scikit-learn?

Scikit-learn охватывает весь цикл создания классического искусственного интеллекта. Она предоставляет инструменты для 6 ключевых задач:

1. **Предобработка данных (Preprocessing)**: Нейросети не понимают текст или разный масштаб чисел. Библиотека умеет автоматически приводить данные к единому масштабу (StandardScaler) и переводить текст в понятные компьютеру цифры (OneHotEncoder).
2. **Разделение данных (Data Splitting)**: Чтобы проверить честность работы ИИ, его нельзя тестировать на тех данных, на которых он учился. Функция train_test_split разделяет данные на обучающую и проверочную части.
3. **Классификация (Classification)**: Определение, к какой категории относится объект. Примеры задач: Спам/не спам, болен пациент/здоров, мошенническая транзакция/легальная.
4. **Регрессия (Regression)**: Предсказание точного непрерывного числа. Примеры задач: Прогноз курса доллара, стоимости квартиры, температуры на завтра.
5. **Кластеризация (Clustering)**: Автоматическое разделение объектов на группы, когда правильных ответов изначально нет. Примеры задач: Сегментация клиентов банка по их поведению для таргета рекламы.
6. **Оценка моделей (Metrics)**: Расчет метрик точности (accuracy_score, mean_squared_error), чтобы инженер понимал, насколько хорошо ИИ справляется со своей задачей.

### 🏢 Где используется Scikit-learn?

- **В бизнесе и бигтехе (включая Google, Spotify, Booking)**: Для рекомендательных систем, предсказания оттока клиентов, финансового скоринга и оценки рисков.
- **В продакшене (Production)**: Для быстрого создания базовых моделей (Baseline). Прежде чем тратить миллионы на обучение гигантской нейросети, AI-инженер за 5 минут пишет модель в sklearn, чтобы понять, есть ли вообще в данных логика.
- **В исследованиях и прототипировании**: Из-за невероятно простого и одинакового для всех алгоритмов синтаксиса (вызов обучения всегда через .fit(), а предсказания — через .predict()).

Пример кода:

```
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import RandomForestClassifier

# 1. Разбиваем данные на обучение и тест (80/20)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 2. Масштабируем признаки (чтобы модель училась стабильно)
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# 3. Создаем модель «Случайного леса» и обучаем её одной командой!
model = RandomForestClassifier()
model.fit(X_train_scaled, y_train)

# 4. Делаем предсказание
predictions = model.predict(X_test_scaled)
```
