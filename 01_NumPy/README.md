# NumPy 

**NumPy** (Numerical Python) — это фундаментальная библиотека для высокопроизводительных научных вычислений в Python.

Если говорить просто, **NumPy — это Excel на максималках, скрытый внутри Python**. Сам по себе Python работает с большими списками чисел довольно медленно. NumPy решает эту проблему, предоставляя инструмент под названием **ndarray (многомерный массив)**, который написан на языках C и Fortran. Благодаря этому математические операции с миллионами чисел происходят **в сотни раз быстрее**, чем в обычном Python.

```
import numpy as np
```

Пример кода:

```
import numpy as np

# 1. Создаем матрицу 3х3 (например, мини-изображение)
matrix = np.array([[1, 2, 3], , 
                   [7, 8, 9]])

# 2. Изменяем форму: делаем из нее вектор 1х9
vector = matrix.reshape(-1)
print("Плоский вектор:", vector)

# 3. Магия векторизации: умножаем всю матрицу на 2 одной командой
double_matrix = matrix * 2

# 4. Работа с осями: находим среднее значение в каждом столбце
column_means = matrix.mean(axis=0)
print("Среднее по столбцам:", column_means)

# 5. Фильтрация: выбираем только четные числа
even_numbers = matrix[matrix % 2 == 0]
print("Только четные:", even_numbers)
```
