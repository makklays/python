# Pandas 

**Pandas** — это самая популярная библиотека на Python для обработки, очистки и анализа структурированных данных

**Pandas — это полноценный Excel (или SQL) внутри вашего Python-кода**. Он позволяет загружать данные из файлов (CSV, Excel, JSON, SQL-баз), давать столбцам понятные имена (например, «Цена», «Возраст», «Дата») и манипулировать ими с помощью простых команд.

### 🧱 Две главные структуры данных в Pandas

- 1. Series (Серия): Это одномерный массив данных. Представьте себе один отдельный столбец в Excel (например, список всех цен). У каждого элемента есть свой индекс (номер строки).
- 2. DataFrame (Датафрейм): Это двумерная таблица. Представьте себе весь лист Excel. DataFrame состоит из множества Series (столбцов), у которых общие индексы строк и есть заголовки. 85% времени вы будете работать именно с DataFrame.

### ⚙️ Зачем конкретно AI-инженер использует Pandas?

В цикле разработки искусственного интеллекта Pandas закрывает следующие ключевые задачи:

- **Чтение и сохранение данных**: Мгновенная загрузка гигантских файлов одной строчкой кода (например, pd.read_csv('dataset.csv') или pd.read_excel()).
- **Очистка от «мусора» (Data Cleaning)**: Удаление дубликатов строк, поиск и заполнение пропущенных значений (например, замена пустых ячеек средним значением по столбцу).
- **Фильтрация и группировка**: Возможность за долю секунды выбрать строки по условию (например: «выбрать всех пользователей из Киева старше 25 лет, которые совершили покупку») или сгруппировать данные (.groupby()) для подсчета статистики.
- **Создание новых признаков (Feature Engineering)**: Создание новых столбцов на основе старых (например, из столбца «Дата рождения» сделать столбец «Возраст»), что критически важно для точности ML-моделей.
- **Слияние таблиц**: Объединение нескольких разных таблиц в одну общую по ключевому полю (аналог операции JOIN в SQL или функции ВПР в Excel) с помощью методов .merge() или .concat().
